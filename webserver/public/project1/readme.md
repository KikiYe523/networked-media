## Resources and Assistance

- [MDN Web Docs](https://developer.mozilla.org/) — Referenced for HTML elements, CSS Grid, positioning, backgrounds, fonts, links, and images.
- [Image-Map.net](https://www.image-map.net/) — Used to generate coordinates for the clickable image maps.
- [Whole Foods Receipt Template](https://www.receipt.dev/templates/grocery/whole-foods-receipt) — Used for the receipt poem design.
- Adobe Photoshop — Used to process images and prepare layered compositions that would otherwise require more advanced CSS positioning.
