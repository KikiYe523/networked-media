 All photographs are my own, recorded for this project.
- The soundtrack is my own work, originally made for a high-school project and converted to MP3 for this site.
- Adobe Photoshop: object cutouts and preparation of the photograph sequences.
- Adobe Illustrator: receipt typography, illustrations, and layouts.
- cloud.cb: noise, red boxes, and distorted details in the processed final frames.

I used the class examples as a foundation and consulted technical references for additional methods. The main references are [MDN Web Docs](https://developer.mozilla.org/) and the [p5.js reference](https://p5js.org/reference/), including [class manipulation](https://developer.mozilla.org/en-US/docs/Web/API/Element/classList), [Date timestamps](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date/getTime), [CSS transitions](https://developer.mozilla.org/en-US/docs/Web/CSS/transition), [blur filters](https://developer.mozilla.org/en-US/docs/Web/CSS/filter), and [audio autoplay](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay).
